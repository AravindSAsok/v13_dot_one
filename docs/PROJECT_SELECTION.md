# Project selection

## Featured six

1. **EvidencePilot** — strongest research/evidence story: retrieval, grounded answers, claim auditing and explicit retrieval evaluation.
2. **TrackCake** — live product story: three food-entry modes, multiple AI providers, review-before-save and optional user-scoped cloud persistence.
3. **Hourly** — strongest correctness story: timestamp-derived calculations, break threshold edge cases, timezone boundaries, database locking and RLS.
4. **Maplewood AI Front Desk** — agent/MCP story: deterministic safety gate, verification, tool boundaries and structured evaluation; synthetic prototype clearly labelled.
5. **ClashCommand** — full-stack domain modelling story: Next.js, auth/roles, relational model, API and external data synchronization.
6. **ProfBot** — document intelligence story: local BM25-style retrieval, abstention, source ID validation, Argon2id and owner-scoped storage.

## Supporting archive

- Openfolio: Cloudflare/edge MVP; kept in supporting archive until its public maturity and deployment story are stronger.
- ACME Salary Management: backend assessment demonstrating server-side pagination and relational aggregates.
- ProfDoc AI v2 and Mini RAG: additional research prototypes; grouped in archive to avoid repeating the ProfBot/EvidencePilot story.

## Selection principle

The featured list balances applied AI, backend correctness, full-stack product delivery and developer-facing architecture. Prototypes and MVPs are labelled honestly. No GitHub star counts, user counts, revenue or unsupported performance claims are used.
