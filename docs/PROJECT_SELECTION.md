# Project selection

## Current state

The inherited portfolio content currently has five featured entries: EvidencePilot, ProfBot AI, Hourly, Practice Management and Multi-Agent Workflow Automation.

This is a baseline inventory, not the final six-project selection required by the v13.1 brief.

## Selection standard

Before promoting a project to a flagship case study, inspect its actual repository source, package manifest, application architecture, persistence layer, authentication and authorization, APIs, tests, deployment configuration, security controls, demo and limitations.

Do not treat README promises or portfolio copy as proof of implemented functionality. Do not invent evaluation metrics, user counts, performance figures or production maturity.
