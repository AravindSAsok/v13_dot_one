## Selected six

1. EvidencePilot — applied AI, retrieval, and evidence review.
2. TrackCake — shipped full-stack product with multiple AI provider integrations.
3. Maplewood AI Front Desk — deterministic-first MCP agent and safety boundaries.
4. Hourly — timestamp-based domain logic and focused test coverage.
5. ClashCommand — relational full-stack domain model, auth, validation, and external sync.
6. Openfolio — developer tooling with GitHub OAuth, Cloudflare D1, token encryption, and server-rendered public pages.

ProfBot remains in the archive because it is technically substantial but overlaps EvidencePilot's document-QA/RAG positioning. ACME Salary Management remains in the archive as a focused Node.js/SQLite API example; Openfolio provides a broader developer-tool and security story. Practice Management and Multi-Agent Workflow Automation were not selected because the copied portfolio entries did not provide a verifiable source repository link.

## Evidence boundaries

The audit does not claim that every available test suite has passed, that every live demo is reachable, or that every deployment is production-grade. Those checks remain part of release QA.
